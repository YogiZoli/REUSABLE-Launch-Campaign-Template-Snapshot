# REUSABLE Launch Campaign Template Snapshot

Reusable Jeff Walker style product launch for GoHighLevel. One sub-account, one snapshot
("REUSABLE Launch Campaign Template Snapshot"), many launches. Every launch only changes custom values.

- `docs/dictionary.md`: all custom value keys (frozen).
- `prompts/workflows/`: ready to paste Workflow AI Builder prompts, one file per workflow.
- `prompts/sales-page-generator.md`: Sales Page Generator prompt (added after the Offer Card export).
- `docs/test-plan.md`: test run checklist.

Rules: one CTA per page and per email. Button text fixed, only the link is a custom value.
Bare plain text emails as GHL templates, never inline, zero broadcasts. No secrets in this repo.
Module slot reserved and empty: "WhatsApp (pull model)" (parked until a company exists).
